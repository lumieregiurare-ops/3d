# Depth Light Studio

2Dイラストから奥行きを推定し、ライト・セル陰影・視点の動きで立体的に見せるブラウザツールです。

## 使い方

`index.html` をブラウザ（WebGL2対応）で開くだけで動きます。インストールは不要です。

- 画像は「画像を開く」、ドラッグ&ドロップ、Ctrl+V で読み込めます（透過PNGは背景を自動で切り抜き）
- カーソルの位置に合わせて絵が傾きます
- ライトは最大4灯。位置はパネル内の小さな画面でドラッグして決めます
- 陰影は「通常」と「セル」（アニメ塗り風）を切り替えられます
- 結果はPNGまたは4秒の動画（WebM）で保存できます

## 仕組み

奥行きはAIではなく、輪郭（背景色・透過）と線画からパーツごとに膨らみを推定して作っています。
推定した高さマップでメッシュを変形し、法線ライティング・高さマップのレイマーチによる落ち影・ハイライト・リムライトをシェーダーで計算しています。
